# カー走

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## ゲームの概要
* バイク（？）で走りながら障害物を飛んでかわしていくゲーム。道中にはコインも配置されているので拾えたら拾う。

## ゲームの遊び方
* 障害物が右から流れてくるので スペースキーを押してジャンプでかわす。空中にいる状態でジャンプで二段ジャンプ可能。

## ゲームの実装
### 共通基本機能
* スペースで車が飛ぶ
* コインを拾うとスコアアップ
* ゲームオーバー時、Rキーでリトライ、escキーでゲーム終了

### 分担追加機能
* 無敵（担当：村田）
・サウンド、エフェクト（担当：星野）
・スキン、背景画像制作（わきが）
・ホーム画面制作（きたむら）
・障害物を増やす（担当：秀島）障害物というよりかは、落とし穴の作成をした
